P1qnum — low-precision numerics

C≈54 hCh. 2–3

A C library for fp16, bf16, fp8 (E4M3/E5M2), int8/int4 group quantization and block floating point, with every conversion written as integer bit manipulation: round-to-nearest-even, truncation and stochastic rounding; subnormals, NaN, Inf and saturation handled exactly; and SQNR measured on real model weights.

Start after Ch. 1–2 and Data Lab. Read §3.1–3.6 and §3.11 before the assembly study (A1.6).

Why: KV-cache compression, weight quantization and accelerator formats (BFP, fp8, micro-scaled fp4) all reduce to these bit tricks — and it's where compiler/ISA differences first show up in numbers.

Key ideas & assignments
  • RNE with integers: add 2^(d−1) − 1 + lsb, then shift; carry into the exponent is a feature.
  • Float bit patterns are monotone as integers → ULP distance and exhaustive testing are cheap.
  • Integer quantization costs B + 16/g bits/weight; BFP loses one bit per octave below the block max.

P2cforward — optimized transformer forward pass

C≈60 hCh. 5–6

A llama2.c-style forward pass (RMSNorm, RoPE, GQA attention, SwiGLU) that matches reference logits, then is optimized one technique at a time — loop order, cache blocking, AVX2, multiple accumulators, quantized weights — with every step plotted on a roofline whose ceilings you measured via the memory mountain.

Start after Ch. 5 and §6.1–6.7 (Cache Lab). The reference pass (A2.1) can begin right after P1.

Why: prefill is compute-bound, decode is bandwidth-bound — here you derive it, measure it, and see what 4-bit weights do to the decode ceiling.

Key ideas & assignments
  • One accumulator is bounded by FMA latency; k independent ones approach throughput (§5.7).
  • Tile for L1/L2; derive the miss counts (§6.6).
  • Online softmax: one pass, a running max, a rescaled sum — one invariant.

P3ltrace-ml — interposition tracer & sampling profiler

C≈55 hCh. 7–8

An LD_PRELOAD library that intercepts malloc/free and then the CUDA runtime, logging sizes, timings and call stacks cheaply enough to run under PyTorch; a SIGPROF profiler emitting flame graphs; a fork/exec launcher; and an offline symbolizer.

Start after Ch. 7 and §8.1–8.4 (Shell Lab). Read §8.5 before the profiler (A3.3).

Why: a reusable measurement tool for serving and compiler papers, and the linker/signal machinery that Nsight and CUPTI stand on.

Key ideas & assignments
  • Preloaded objects win symbol lookup; dlsym(RTLD_NEXT) finds the real function.
  • Reentrancy guards and a bump arena keep hooks from recursing into themselves.
  • Sampling is statistics: share ± 1.96·√(p(1−p)/n).

P4pagedkv — allocator, paged KV cache, prefix cache

C≈64 hCh. 9

Malloc Lab done to completion, then a vLLM-style KV manager on mmap'd memory: fixed blocks, block tables, refcounts with copy-on-write, a radix tree for prefix caching, pluggable eviction, a disk tier — plus reuse-distance analysis that measures every policy against Belady's optimal.

Start after all of Ch. 9. The allocator (A4.1) replaces Malloc Lab.

Why: it's the data structure behind PagedAttention and RadixAttention, and it asks the OS question — how far is LRU from optimal — for KV blocks.

Key ideas & assignments
  • Mattson: one reuse-distance histogram gives LRU's miss ratio for every cache size.
  • Belady's MIN evicts the block used furthest in the future; tree structure forces leaf-first eviction.
  • TLB reach with 4 KB vs 2 MB pages, measured on attention gathers.

P5tinyjit — AVX2 JIT for fused tensor ops

C≈58 hCh. 3, 7 (revisit)

A tensor-expression IR compiled at run time to AVX2 machine code: operator fusion, linear-scan register allocation over 16 ymm registers, a masked tail, a RIP-relative constant pool, and optionally a relocatable ELF .o that gcc links.

Start after P4, with a second pass through §3.2–3.7 and §3.11. Re-read §7.4–7.7 before the ELF stretch (A5.6).

Why: it's the last mile of every DL compiler — DAG → loop → bytes — with nothing between you and the numbers.

Key ideas & assignments
  • VEX/ModR/M/SIB encoding, golden-tested byte-for-byte against as.
  • W⊕X: write, then mprotect to execute.
  • Fusing k elementwise ops saves ≈ k× memory traffic on a bandwidth-bound loop.

P6servlet — continuous-batching inference server

C++20≈80 hCh. 10–12

An epoll HTTP/1.1 server streaming tokens over SSE, with an engine thread, lock-free queues, and an iteration-level scheduler doing chunked prefill, KV-aware admission, preemption and prefix-affinity batching — measured with a load generator for TTFT, TPOT and goodput, TSan-clean, with CI and submodules.

Start after Ch. 10–11 (Proxy Lab optional). Read Ch. 12 before the engine thread (A6.3).

Why: a testbed for scheduling and caching ideas where every queue and lock is yours, before you touch vLLM or SGLang.

Key ideas & assignments
  • Short counts are normal; buffers and backpressure make them safe.
  • Parser correctness = any split of the bytes parses identically.
  • Step time ≈ t_w + B·t_tok: batching amortizes the weight read until KV or compute binds.
